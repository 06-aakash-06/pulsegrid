# Resilience and observability

Redis admission Lua AOF replay defect P10-01 is fixed and committed as `2775afb`. A pinned Redis 7 container regression demonstrated that the former ACL loses the synthetic admission hash on replay and emits AOF NOPERM errors. The new disabled-default ACL grants only the replay-time Lua write primitives against the `pg:admission:v1:*` namespace; the authenticated `admission` ACL is unchanged. Before/after regression proves hash and absolute expiry survive restart, disabled default login remains unavailable, and out-of-namespace writes are denied. A real isolated Redis AOF restart and retained Redis planned restart both became ready; bounded startup log scan showed no replay error. Evidence: `redis-aof-before.json`, `redis-aof-regression.json`, `redis-real-restart.json`, `retained-aof-commands.json`, `guard-activation.json`.

Tempo limits and the completed 600-second same-stack observation are recorded in [runtime stability](02-runtime-stability.md). Readiness, metrics, search, authenticated synthetic reads and same-request trace queries succeeded throughout that window. Collector logs also show span loss during Tempo startup/restart: 99 retained Collector error events/5,770 dropped spans in the bounded log tail and 8 isolated startup events/453 spans. Fresh trace queries recovered after readiness, but that does not restore lost telemetry. The loss affected optional traces; no hospital request or business success was inferred from absent telemetry. WAL and retained volumes were preserved. See `evidence/otel-export-drops.json`.

For live alert acceptance, only the isolated Doctor replica was stopped. Prometheus exposed `PulseGridDoctorUnavailable` as pending, then firing after about 148 seconds; the sibling Doctor stayed healthy. The same replica was restarted and became ready; the alert cleared after the recovery hold, about 60 seconds later. The complete sampled transition is in `evidence/alert-recovery.json`. The retained deployment was not fault-injected. Prior isolated broker outage/replay/DLQ, cache outage/recovery, distributed rate limit and manual Surge NORMAL/SURGE/RECOVERY results remain as scoped baseline. No production HA is implied by Compose.

The earlier incomplete monitor queried retained Tempo while emitting test traffic through the isolated gateway; those cross-stack lookups were discarded. The completed replacement queries the matching isolated Tempo and verifies 20/20 previous synthetic request traces. See `evidence/tempo-observation-after.json` and the correction in `02-runtime-stability.md`.
